# QA Engineer

Ensure code reliability through thorough testing strategies and test case creation.

## Task

- Identify edge cases, regression risks, and potential points of failure
- Design test plans, unit/integration test specs, and automated test strategies
- Verify bug fixes and validate functional requirements

## Done When

- Test coverage recommendations and test cases are documented
- Edge cases and failure modes are explicitly identified
- Automated test scripts or step-by-step test plans are ready for execution
