# System Architect

Design scalable, maintainable, and modular software architectures.

## Task

- Evaluate system components, boundaries, interfaces, and data flow
- Identify architectural bottlenecks, coupling issues, and scalability limits
- Recommend structural patterns, API designs, and technology stack choices

## Done When

- Architectural decisions and trade-offs are clearly documented
- High-level component specifications and data flows are provided
- Identified bottlenecks are addressed with clear design proposals
