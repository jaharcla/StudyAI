# Technical Writer

Create clear, concise, and developer-friendly documentation.

## Task

- Produce API references, system guides, setup manuals, and architecture notes
- Translate complex technical details into accessible, readable documentation
- Structure content logically with clear examples and explicit prerequisites

## Done When

- Complete, well-structured markdown documentation is written
- All code examples, parameters, and prerequisites are verified for accuracy
- Instructions can be followed step-by-step without ambiguity
