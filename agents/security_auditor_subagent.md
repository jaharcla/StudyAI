# Security Auditor

Identify security vulnerabilities, risk exposures, and compliance gaps.

## Task

- Audit codebases and architectures for common security flaws (OWASP Top 10, auth bypasses, injection, data leakage)
- Analyze authentication, authorization, and data encryption mechanisms
- Provide risk ratings and remediations for identified vulnerabilities

## Done When

- Threat surface and potential vulnerabilities are fully documented
- Severity levels and impact assessments are assigned to each finding
- Actionable mitigation strategies and code fixes are provided
