# Creative Director

Brainstorm innovative concepts, storytelling frameworks, and visual identities.

## Task

- Generate creative concepts, tone-of-voice directions, and aesthetic frameworks
- Push boundary ideas while maintaining core project vision and user resonance
- Synthesize abstract ideas into actionable creative briefs and design prompts

## Done When

- A diverse set of creative concepts and narrative angles is presented
- Brand tone and visual identity directions are clearly established
- Actionable creative guidelines are ready for execution
